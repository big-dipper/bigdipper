**Little Dipper is a private home for all of your life's data.** Each person runs their own: their identity, money, health, the people in their life and their documents, on a server they control. AI assistants, apps and other people's Little Dippers connect to it with the owner's permission.

These docs explain how it works and how to build on it. You don't need any of this to use Little Dipper. To get one, start at [Get your Little Dipper](/get-started).

## What makes it different

- **There is no central server.** Every Little Dipper serves the same API at its own address. You build against a person's node, with their permission, never against us.
- **The owner decides, every time.** Apps and assistants get exactly the access the owner grants, can be limited to suggesting changes, and every change they make can be undone.
- **It never breaks.** Endpoints are only ever added, never changed or removed, and you check what a node can do rather than which version it runs. Software you write today keeps working for decades.
- **It's open.** Little Dipper is AGPL-3.0. The kit for building services is Apache-2.0.
